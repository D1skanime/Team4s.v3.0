# Phase 114 — UI Design Contract

> Visual and interaction contract for the public fansub-group directory at `/fansubs`.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope:** one new public index page (`/fansubs`) rendering ALL fansub groups as a
> sortable table, each row linking to the existing detail page `/fansubs/[slug]`, plus
> activation of the currently-disabled AppShell nav entry „Fansub-Gruppen".

---

## Locked Constraints (non-negotiable, from CLAUDE.md)

These are hard gates the checker and executor MUST enforce. They are not defaults.

| # | Constraint | Source |
|---|-----------|--------|

|-----------|-----------------------------|-------------------|
| `PageHeader` | `{ title, description?, eyebrow?, actions?, breadcrumbs? }` | Page title + one-line description |
| `Table` | `{ variant?: 'default'\|'compact'\|'selectable'\|'withActions', caption?, containerClassName? }` — use `variant="selectable"` for row-hover affordance | Directory container |

**Round logo cell:** render the group `logo_url` as a **round** image at **32px** (allowed range
32–40px; pick 32 for row density and to match the existing 32px avatar treatment). When `logo_url`
is null/empty, render an **initials placeholder** derived from the group name (reuse the
`initials()` convention from `AvatarStack`). The logo image needs `alt=""` (decorative; the group
name is the adjacent accessible text) and the row link carries the accessible name.

## Table Columns (locked)

Default sort: **Release-Versionen descending**, **group name ascending as tie-break** (CONTEXT D-05).
Whether sorting is server-side via `getFansubList()` params or client-side is a build detail
(Claude's Discretion) as long as this default ordering holds.

| # | Column header (de) | Content | Data source | Alignment |
|---|--------------------|---------|-------------|-----------|
| 1 | Fansub-Gruppe | Round logo (32px, initials fallback) + group name; whole row/name links to `/fansubs/[slug]` | `FansubGroup.logo_url`, `.name`, `.slug` | left |
| 2 | Anime-Projekte | Project count | Detail page uses `profile.projects.length`; the list payload does NOT yet expose a project count. Smallest additive metric addition allowed (CONTEXT D-03) — planner decides field name. Do NOT substitute `anime_relations_count` silently, semantics differ | numeric, left-aligned per primitive default |
| 3 | Release-Versionen | Release-version count (sort key) | `FansubGroup.release_versions_count` (already in list payload) | numeric |
| 4 | Mitglieder | Member count | `FansubGroup.members_count` exists in list payload; detail page computes `countVisibleTeamMembers`. Prefer parity with the detail-page count — if the list `members_count` diverges from the visible-team count, planner reconciles with the smallest additive change (D-03) | numeric |

**Column semantics MUST match the detail-page metric labels exactly** (C-5). Metric numbers are
plain text in cells — no badges, no accent color, no sparklines (out of scope, „klein bleiben").

**Row link contract:** each row navigates to the existing `/fansubs/[slug]` detail route. Use a
real Next `<Link>` on the group name (and ideally a full-row click affordance) — never a native
`<button>` faux-link. Keyboard focusable; visible focus ring (accent). No new detail route is created.

## Layout & Responsive

- Page shell: `PageHeader` above the `Table`, same page rhythm as other public list pages.
- The `Table` primitive is horizontally scrollable below `min-width: 640px` (built into `.tableWrap`),
  so the four columns stay intact on smartphones without a bespoke card fallback. No separate mobile
  card layout is in scope.
- Spacing between header and table: `--space-5` (24px) or `--space-6` (32px); do not invent new gaps.
- No banner, no hero image, no filters, no search box, no active/dormant grouping (all deferred).

## Accessibility

- Table uses semantic `<table>`/`<th scope="col">` via the primitives; column headers are real `TableHeaderCell`s.
- Each row's group name is a focusable `<Link>` with a discernible accessible name; visible focus ring in accent.
- Logo `<img>` is decorative (`alt=""`); the accessible name comes from the group-name link text.
- Empty/error surfaces use `EmptyState`/`ErrorState` primitives (icon marked `aria-hidden`).
- Horizontal scroll region (`.tableWrap`) remains keyboard-scrollable on narrow viewports.
