| public profile project list -> navigation helper | Public DTO determines visible navigation targets. |
| anime group relations -> hero coop links | Same-Anime group relations become public group profile links. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-102-03-01 | Spoofing | same-Fansub navigation label | mitigate | Build previous/next only from current Fansub profile projects, never from same-Anime `other_groups`. |
| T-102-03-02 | Information Disclosure | `Coop mit` links | mitigate | Render only existing public Fansub group profile slugs already returned by public reads. |
| T-102-03-03 | Tampering | route href generation | mitigate | Use DTO `anime_slug` and `fansubSlug`; do not infer slugs from titles. |
</threat_model>
