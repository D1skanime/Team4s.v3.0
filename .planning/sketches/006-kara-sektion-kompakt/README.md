# Sketch 006: Kara-Sektion kompakt

## Design Question

Wie kann die Kara-Sektion auf Desktop und Mobile lebendiger wirken, ohne die technische Übersicht und die Abspielaktion zu verlieren?

## How to View

Öffne `index.html` im Browser. Die Datei ist ein eigenständiger HTML-Sketch ohne Build-Schritt.

## Varianten

- **A: Timeline-Fokus** — die Timeline ist der visuelle Anker, die Karten bleiben gleichwertig und zeigen die wichtigsten Daten.
- **B: Kompakte Karten** — die Abspielaktion sitzt direkt rechts neben den Metadaten, Rollen werden zunächst zusammengefasst.

## What to Look For

- Wirkt die Timeline als Orientierung ausreichend stark?
- Ist die Abspielaktion sofort auffindbar?
- Ist die reduzierte Rollenanzeige verständlicher als die lange Liste?
- Welche Variante funktioniert auf Desktop und Mobile besser?
