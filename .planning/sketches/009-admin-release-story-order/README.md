# Sketch 009: Admin Release Story Order

## Design Question

Wie kann die Medienliste im Release-Editor Bilder und automatisch verfügbare Kara-Segmente gemeinsam sortieren, während die fachlichen Tabellen getrennt bleiben?

## How to View

`index.html` im Browser öffnen. Drag & Drop sowie ↑/↓-Buttons sind im Sketch aktiv.

## Varianten

- **A: Kombinierte Liste** — dichte, präzise Reihenfolge mit Detailpanel für das ausgewählte Kara.
- **B: Story-Canvas** — größere visuelle Sequenz für die redaktionelle Dramaturgie.
- **C: Projektion** — zeigt explizit die getrennten Quellen und die gemeinsame Story-Projektion.

## Was du vergleichen solltest

- Ist die Trennung zwischen `media` und `theme_segment` klar genug?
- Wird das automatisch auftauchende Kara ohne Fake-Media verständlich?
- Ist Drag & Drop bei vielen Einträgen weiterhin präzise?
