# Context

The Anime create page still showed a redundant "Neu / Aus meiner Bibliothek" card above the provider search. Its Basisdaten form also used the older mixed grid and included a create-only "Titel bereit" status row, so it did not match Anime edit.

Decision: remove the redundant discovery card from the create page and reuse the existing semantic Basisdaten row classes already used by edit: main title, three classification fields, two numeric fields, two language fields, and folder path.
