<objective>
Schließt einen dokumentierten, aber nie GSD-abgenommenen Phase-117-Feature-Gap: Das Backend für
geteilte Karaoke-Segmente (Zuweisung an mehrere Release-Versionen + Per-Folge-Zeit-Override) ist
fertig und ein Teil der Frontend-Verdrahtung (Hook-Exporte, Helfer, `is_shared`-gated Override-UI)
existiert bereits aus einer früheren, nicht-GSD-approved Session — aber drei konkrete UX-Lücken
verhindern, dass Admins das Feature tatsächlich nutzen können.

Purpose: Admins können (1) einen Segment-Vorschlag aus einer anderen Release-Version ohne Duplikat
übernehmen, (2) für JEDES Segment Folgen-Zuweisungen verwalten (nicht erst nachdem es zufällig schon
geteilt ist — Henne-Ei-Problem), und (3) für eine geteilte Folge nur die Startzeit verschieben
(Ende folgt automatisch der Basis-Dauer), statt zwei unabhängige Zeitfelder pflegen zu müssen.
Output: Verdrahtete, live auf :3000 testbare UI-Änderungen in drei bestehenden Dateien plus einer
neuen kleinen Komponente; Backend bleibt unangetastet.
</objective>
