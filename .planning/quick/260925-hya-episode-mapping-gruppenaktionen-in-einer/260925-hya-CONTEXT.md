# Quick Task Context

Die Gruppenspalte soll näher an der Dateispalte stehen. Die Gruppenbedienung soll außerdem eine gemeinsame Zeile bilden: Suchfeld, „Als Chip“, „Ab hier“ und „Ab hier entfernen“.

Entscheidung: Das Mapping-Grid erhält kleinere Spaltenabstände; die vier Gruppencontrols werden in ein gemeinsames Grid verschoben und brechen nur bei schmalen Layouts um.
