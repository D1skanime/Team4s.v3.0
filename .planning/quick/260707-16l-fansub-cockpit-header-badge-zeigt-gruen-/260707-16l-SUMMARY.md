# Phase Quick 260707-16l: Fansub-Cockpit Header-Badge zeigt grün bei Theme-Segmenten Summary

Backend now computes `has_theme_segments` via a correlated EXISTS subquery (theme_segments joined to themes, scoped by episode range) in all three fansub-release read paths, and the frontend badge in the collapsed release header combines `has_theme_assets || has_theme_segments` so episodes with OP/ED segments but no uploaded theme video also show the green "Themes" badge.

## What Was Built

**Task 1 (Backend):** Added `HasThemeSegments bool` (`json:"has_theme_segments"`) to `AdminFansubReleaseSummary`. Added an `EXISTS (SELECT 1 FROM theme_segments ts JOIN themes th ON th.id = ts.theme_id WHERE th.anime_id = a.id AND ep.episode_number ~ '^[0-9]+$' AND (ts.start_episode IS NULL OR ts.start_episode <= ep.episode_number::int) AND (ts.end_episode IS NULL OR ts.end_episode >= ep.episode_number::int))` subquery — identical in all three queries: `ListFansubAnimeReleasesPage`, `GetCanonicalFansubAnimeReleaseSummary`, `GetAdminReleaseByID`. Added `&item.HasThemeSegments` to the corresponding `Scan(...)` calls. Followed RED (failing source-inspection test) → GREEN (implementation) TDD flow.

**Task 2 (Frontend):** Added optional `has_theme_segments?: boolean` to `AdminFansubRelease`. `ReleaseRowDetails.tsx` now derives `hasThemes = release.has_theme_assets || Boolean(release.has_theme_segments)` and renders the header Badge as `success`/"Themes" or `muted`/"Keine Themes" based on that combined flag (the previous "N Theme(s)" count text driven by `cards.length` was dropped in favor of plain "Themes", per plan/user confirmation). Updated all release mocks/factories in `page.test.tsx` (7 sites), `ReleaseThemeDrawerSection.test.tsx`, and `fansubEditReleaseHelpers.test.ts` with an explicit `has_theme_segments: false` default so existing cases keep their prior expected behavior. Added a new test in `page.test.tsx` proving a release with `has_theme_assets: false, has_theme_segments: true` renders "Themes" (not "Keine Themes") in the collapsed header.
