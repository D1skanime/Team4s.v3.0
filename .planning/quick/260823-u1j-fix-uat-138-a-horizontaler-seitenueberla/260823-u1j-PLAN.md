<objective>
Fix UAT-138-A: horizontal page overflow on narrow viewports (394px), caused by `display: grid` rules in the global UI primitive stylesheet (`ui.module.css`) that omit `grid-template-columns`. Without an explicit column template, the browser's implicit single column uses `auto` sizing, which grows to the widest child's intrinsic/min-content width instead of respecting the container's own box width. On `/admin/users/4`, tab "Rollen & Rechte", this measured as `document.scrollWidth=726` vs `clientWidth=394`, traced to `.card` computing `grid-template-columns: 673.778px` because a wide capability table sits inside a `.cardSection`.

Purpose: Restore correct responsive containment for the global `Card` and `Tabs` primitives without changing their visual appearance for normal content, and without touching component/JSX code.
Output: Updated `frontend/src/components/ui/ui.module.css` with `grid-template-columns: minmax(0, 1fr);` added to `.card` and `.tabs`; a SUMMARY.md documenting exactly which selectors changed and why.
</objective>
