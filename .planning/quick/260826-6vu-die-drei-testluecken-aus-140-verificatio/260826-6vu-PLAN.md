Control flow facts (verified by direct read, load-bearing for test design):
- `GetReviewDelegations`: `permissionActorFromContext` -> path parse -> `h.authorize(...)` calls
  `permissionSvc.CanForFansubGroup(ctx, actor, permissions.ActionFansubGroupMembersManage, group)`;
  on deny writes ONE audit entry via `auditPermissionDenied` (event `"review_delegation.inspect.denied"`,
  `Outcome: "denied"` is set inside `auditPermissionDenied` itself) and returns 403 -> THEN
  `h.membership(...)` calls `targetRepo.LockTargetMembership`; `repository.ErrNotFound` -> 404
  (readRepo is never touched at this point) -> THEN `readRepo.LoadDelegationSnapshot(ctx, member.MembershipID)`
  -> 200 with `{"data": []ReviewDelegationRow}` (3 rows, fixed order per `reviewDelegationActionOrder`).
- `MutateReviewDelegation` does **NOT** call `permissionSvc.CanForFansubGroup` at all — authorization
  for the mutation itself is enforced downstream by the domain service and surfaced only via
  `services.ErrReviewCapabilityDenied` -> 403. Order: `permissionActorFromContext` -> path parse ->
  `c.ShouldBindJSON(&req)` (bind failure -> 400) -> `req.ActionCode==""||req.Grant==nil` -> 400
  ("action_code und grant sind erforderlich") -> `isReviewDelegationAction(action)` false -> 400
  ("action_code ist keine delegierbare review-aktion") — **all before `h.membership(...)` is ever
  called**, i.e. `targetRepo.LockTargetMembership` and both mutation methods have zero calls for these
  two 400 cases -> `h.membership(...)` (foreign/missing target -> 404, mutation service never called) ->
  builds `services.ReviewDelegationCommand{Actor: actor, TargetMembershipID: member.MembershipID, Action: action}`
  -> `*req.Grant` true calls `mutationSvc.GrantDelegation(ctx, cmd)`, false calls `RevokeDelegation` ->
  error mapping: `services.ErrReviewCapabilityDenied` -> 403, `services.ErrReviewDelegationTargetIneligible`
  -> 422, `services.ErrReviewActionInvalid` -> 400, anything else -> 500 -> success -> 200 with
  `{"data": {"action_code": req.ActionCode, "granted": *req.Grant}}`.
