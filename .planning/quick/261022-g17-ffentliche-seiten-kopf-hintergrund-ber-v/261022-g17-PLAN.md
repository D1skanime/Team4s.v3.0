<objective>
Fix the reported bug: on exactly three public pages (group page `/fansubs/<slug>`, project page
`/fansubs/<slug>/fansubprojekt/<anime>`, release page `.../releases/<id>`), the blurred
banner/backdrop "head mood" stops hard at the `--public-page-max-width` content edge at wide
viewports instead of bleeding to the screen edges, leaving large flat white margins on both sides.
`/anime/<id>` (AnimeBackdropRotator) already renders full-bleed correctly and is NOT touched.

**Confirmed root cause (verified live via Playwright + pixel screenshots in the running
`team4sv30-frontend` container during planning, not just by reading CSS):** all five existing
backdrop elements already use the textbook full-bleed trick (`left: calc(50% - 50vw); width:
100vw`), which is mathematically correct -- but each one sits inside an ancestor that ALSO
declares `overflow-x: clip` (or `overflow-clip-margin`, which does not work in practice here)
while being width-capped to `--public-page-max-width`. The 100vw-wide backdrop box is computed
correctly, then immediately clipped back down to the ancestor's own narrow box by that ancestor's
own `overflow-x: clip`. This is NOT the classic 100vw-scrollbar trap -- `body { overflow-x: clip }`
in `frontend/src/styles/globals.css:212-221` already exists globally and correctly prevents that.
The bug is three REDUNDANT, locally-placed `overflow-x: clip` declarations on width-capped
ancestors that shadow the already-correct global rule:

| # | Page | Clipping ancestor (bug) | File:Line |
|---|------|--------------------------|-----------|
| 1 | Group hero + both section bands | `.page` and `.sectionBand` | `frontend/src/app/fansubs/[slug]/page.module.css:5` and `:278` |
| 2 | Project "Neuestes Release" band (reuses file above) | `.sectionBand` (same file, shared by import) | same as #1 -- fixing it once fixes both pages' section bands |
| 3 | Release page hero | `.pageWithBackdrop` | `frontend/src/app/anime/[id]/group/[groupId]/releases/[releaseVersionId]/page.module.css:11-14` (`overflow-x: clip; overflow-clip-margin: 50vw;` -- the margin trick does not prevent clipping in practice, confirmed by screenshot) |

**Deviation from the task brief's assumption (confirmed live, must be stated explicitly):** the
project page's TOP hero backdrop (`HeroSection.tsx`'s `.heroBackdrop`,
`frontend/src/app/anime/[id]/group/[groupId]/page.module.css:44-63`) is **already full-bleed and
correct today** -- its clipping ancestor chain terminates at `<body>`, not at a width-capped
local ancestor (`.page` on this specific page never declares `overflow-x: clip`). Only the
project page's SECOND backdrop -- the "Neuestes Release" band
(`frontend/src/app/anime/[id]/group/[groupId]/sections/ReleasesSection.tsx:40-48`, which literally
imports and reuses `fansubs/[slug]/page.module.css`'s `.sectionBand`/`.sectionBandBackdrop`) -- is
broken, for the same reason as #1/#2 above. The task still correctly identifies three pages as
affected; the project page's bug is just in its second backdrop, not its first.

**Confirmed: no other public page shares this mechanism.** `grep -rn "calc(50% - 50vw)" frontend/src/app

    ```tsx
    import styles from './PublicHeaderBackdrop.module.css'

    interface PublicHeaderBackdropProps {
      imageUrl: string | null | undefined
      className?: string
    }

    /**
     * Gemeinsamer Full-Bleed-Kopf-Hintergrund fuer oeffentliche Gruppen-, Projekt- und
     * Release-Seiten (quick-261022-g17). Rendert NUR das Hintergrund-Element
     * (position:absolute, volle Bildschirmbreite via calc(50% - 50vw)/100vw).
     *
     * WICHTIG: kein Vorfahre dieses Elements bis zu <body> darf overflow-x:clip/hidden
     * setzen -- sonst greift die Clip-Ancestor-Falle und der Hintergrund wird an der
     * Inhaltskante abgeschnitten. Scrollbar-Sicherheit kommt global aus
     * body { overflow-x: clip } (frontend/src/styles/globals.css).
     *
     * className ist fuer seiten-spezifisches Tuning gedacht (top/bottom/filter/transform/
     * opacity/background-size/background-position/::after-Verlauf unterscheiden sich je
     * Seite). .backdrop selbst setzt top/bottom/background-size/background-position NICHT,
     * jede *Tuning-Klasse muss sie selbst setzen.
     */
    export function PublicHeaderBackdrop({ imageUrl, className }: PublicHeaderBackdropProps) {
      if (!imageUrl) return null
      return (
        <div
          data-testid="public-header-backdrop"
          className={`${styles.backdrop} ${className ?? ''}`.trim()}
          style={{ backgroundImage: `url("${imageUrl}")` }}
          aria-hidden="true"
        />
      )
    }
    ```

    ```javascript
    import { mkdirSync } from 'node:fs'
    import { chromium } from 'playwright'

    const BASE = 'http://127.0.0.1:3000'
    const VIEWPORTS = [
      { width: 2560, height: 1200, label: '2560x1200' },
      { width: 1440, height: 900, label: '1440x900' },
      { width: 375, height: 812, label: '375x812' },
    ]
    const SHOT_DIR = '/tmp/public-header-backdrop-evidence'

    const IMAGE_CARD_CASES = [
      { name: 'release-transparent-logo', path: '/fansubs/new-subs/fansubprojekt/buddy-complex/releases/49' },
      { name: 'release-normal-image', path: '/fansubs/new-subs/fansubprojekt/buddy-complex/releases/27' },
    ]
    const IMAGE_CARD_VIEWPORTS = [
      { width: 1440, height: 900, label: '1440x900' },
      { width: 375, height: 812, label: '375x812' },
    ]

    async function resolveReleasePath(page) {
      const projectPath = '/fansubs/strawhat-subs/fansubprojekt/11eyes'
      const fallback = `${projectPath}/releases/164`
      try {
        const res = await page.request.get(`${BASE}${projectPath}`)
        const html = await res.text()
        const match = html.match(/releases\/(\d+)/)
        return match ? `${projectPath}/releases/${match[1]}` : fallback
      } catch {
        return fallback
      }
    }

    async function main() {
      mkdirSync(SHOT_DIR, { recursive: true })
      const browser = await chromium.launch()
      const page = await browser.newPage()
      const releasePath = await resolveReleasePath(page)
      const targets = [
        { name: 'group', path: '/fansubs/new-subs' },
        { name: 'project', path: '/fansubs/strawhat-subs/fansubprojekt/11eyes' },
        { name: 'release', path: releasePath },
      ]

      const results = []
      const failures = []

      for (const viewport of VIEWPORTS) {
        for (const target of targets) {
          await page.setViewportSize({ width: viewport.width, height: viewport.height })
          await page.goto(`${BASE}${target.path}`, { waitUntil: 'networkidle' })

          const measurement = await page.evaluate(() => {
            const vw = window.innerWidth
            const scrollWidth = document.documentElement.scrollWidth
            const clientWidth = document.documentElement.clientWidth
            const backdrops = Array.from(
              document.querySelectorAll('[data-testid="public-header-backdrop"]'),
            ).map((el) => {
              const r = el.getBoundingClientRect()
              return { left: r.left, width: r.width, right: r.right }
            })
            const rootStyle = getComputedStyle(document.documentElement)
            const maxWidthPx = parseFloat(rootStyle.getPropertyValue('--public-page-max-width'))
            const gutterPx = parseFloat(rootStyle.getPropertyValue('--public-page-gutter'))
            const expectedContentWidth = Math.min(maxWidthPx, vw - gutterPx)
            const contentNode = document.querySelector(
              '[class*="heroFg"], [class*="gridSection"], [class*="pageHeaderRow"]',
            )
            const contentWidth = contentNode ? contentNode.getBoundingClientRect().width : null
            return { vw, scrollWidth, clientWidth, backdrops, expectedContentWidth, contentWidth }
          })

          const shotPath = `${SHOT_DIR}/${target.name}-${viewport.label}.png`
          await page.screenshot({ path: shotPath, fullPage: false })

          const noHorizontalScroll = measurement.scrollWidth <= measurement.clientWidth
          const hasBackdrop = measurement.backdrops.length > 0
          const backdropFullWidth = measurement.backdrops.every(
            (b) => Math.abs(b.width - measurement.vw) <= 2,
          )
          const contentWidthOk =
            measurement.contentWidth === null ||
            Math.abs(measurement.contentWidth - measurement.expectedContentWidth) <= 4

          results.push({
            viewport: viewport.label,
            page: target.name,
            path: target.path,
            ...measurement,
            noHorizontalScroll,
            hasBackdrop,
            backdropFullWidth,
            contentWidthOk,
            screenshot: shotPath,
          })

          if (!noHorizontalScroll) {
            failures.push(
              `${target.name}@${viewport.label}: horizontal scroll (scrollWidth ${measurement.scrollWidth} > clientWidth ${measurement.clientWidth})`,
            )
          }
          if (!hasBackdrop) {
            failures.push(`${target.name}@${viewport.label}: no public-header-backdrop element found`)
          }
          if (hasBackdrop && !backdropFullWidth) {
            failures.push(
              `${target.name}@${viewport.label}: backdrop width(s) ${JSON.stringify(measurement.backdrops.map((b) => b.width))} != viewport width ${measurement.vw}`,
            )
          }
          if (!contentWidthOk) {
            failures.push(
              `${target.name}@${viewport.label}: content width ${measurement.contentWidth} != expected ${measurement.expectedContentWidth}`,
            )
          }
        }
      }

      // Image-card regression checks (quick-261022-g17 addendum): the release hero image must no
      // longer carry a box-shadow "card" behind it, while a normal (non-transparent) image keeps
      // its own border-radius corner rounding.
      for (const viewport of IMAGE_CARD_VIEWPORTS) {
        for (const target of IMAGE_CARD_CASES) {
          await page.setViewportSize({ width: viewport.width, height: viewport.height })
          await page.goto(`${BASE}${target.path}`, { waitUntil: 'networkidle' })

          const imageMeasurement = await page.evaluate(() => {
            const img = document.querySelector('[class*="heroImage"]')
            if (!img) return null
            const cs = getComputedStyle(img)
            return { boxShadow: cs.boxShadow, borderRadius: cs.borderRadius }
          })

          const shotPath = `${SHOT_DIR}/${target.name}-${viewport.label}.png`
          await page.screenshot({ path: shotPath, fullPage: false })

          results.push({
            viewport: viewport.label,
            page: target.name,
            path: target.path,
            imageMeasurement,
            screenshot: shotPath,
          })

          if (!imageMeasurement) {
            failures.push(`${target.name}@${viewport.label}: no [class*="heroImage"] element found`)
            continue
          }
          const noShadow = imageMeasurement.boxShadow === 'none'
          if (!noShadow) {
            failures.push(
              `${target.name}@${viewport.label}: heroImage still has a box-shadow (${imageMeasurement.boxShadow}) -- the card effect was not removed`,
            )
          }
          if (target.name === 'release-normal-image') {
            const hasRadius = imageMeasurement.borderRadius !== '0px' && imageMeasurement.borderRadius !== ''
            if (!hasRadius) {
              failures.push(
                `${target.name}@${viewport.label}: heroImage lost its own corner rounding (border-radius: ${imageMeasurement.borderRadius})`,
              )
            }
          }
        }
      }

      console.log(JSON.stringify(results, null, 2))
      await browser.close()

      if (failures.length > 0) {
        console.error(`FAILURES:\n${failures.join('\n')}`)
        process.exitCode = 1
        return
      }
      console.log('ALL CHECKS PASSED')
    }

    await main()
    ```
