<objective>
Behebe den 400-Fehler "release_variant_id ist erforderlich", der im Fansub-Gruppen-Cockpit (`/admin/fansubs/[id]/edit`) beim Ausklappen eines Releases fuer Nicht-Plattform-Admins mit `segments.manage`-Capability auftritt (z.B. CSubs-Leader).

Ursache (bereits diagnostiziert, siehe Orchestrator-Kontext): `getAdminAnimeThemeSegments` in `frontend/src/lib/api.ts` unterstuetzt keinen `release_variant_id`-Parameter, obwohl das Backend (`requireSegmentManage` in `backend/internal/handlers/admin_content_anime_theme_segments.go`) diesen fuer Nicht-Admins zwingend voraussetzt. `useFansubReleaseData.ts` ruft die Funktion ohne die verfuegbare `release.release_version_id` auf.

Purpose: CSubs-Leader (und andere Nicht-Plattform-Admins mit `segments.manage`) muessen Theme-Segmente im Fansub-Cockpit laden koennen, ohne dass die Backend-Permission-Pruefung aufgeweicht wird — reine Frontend-Korrektur, die die bereits vorhandene ID durchreicht.

Output: Erweiterter API-Helper mit optionalem `releaseVariantId`-Parameter, angepasster Aufruf in `useFansubReleaseData.ts`, aktualisierte/erweiterte Tests in `page.test.tsx`.
</objective>
