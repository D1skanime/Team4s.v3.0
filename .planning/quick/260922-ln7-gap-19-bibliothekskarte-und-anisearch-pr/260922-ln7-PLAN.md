Drei benannte Exporte, alle reine Funktionen ohne Seiteneffekte:

1. export function stripTrailingYearSuffix(value: string): string — entfernt über
   value.replace(/\s*\(\d{4}\)\s*$/, "").trim() ein angehängtes "(YYYY)"-Suffix (genau vier Ziffern in
   Klammern) vom Ende des Strings. Andere Klammerinhalte (z. B. "(Jellyfin)", "(Uncut)") bleiben
   unangetastet, weil das Muster exakt vier Ziffern verlangt.

2. export function extractFolderNameFromPath(rawPath?: string | null): string — normalisiert
   (rawPath ?? "").trim() durch .replace(/\\/g, "/") (dieselbe Slash-Konvention wie
   path.Base(strings.ReplaceAll(path, "\\", "/")) im Backend, siehe Interfaces-Block), splittet an "/",
   trimmt jedes Segment und filtert leere Segmente heraus (z. B. bei einem trailing slash). Gibt das
   letzte verbleibende, nicht-leere Segment zurück, oder "" wenn keins übrig bleibt.

3. export function buildDisplayFolderName(rawPath?: string | null): string — kombiniert beide:
   stripTrailingYearSuffix(extractFolderNameFromPath(rawPath)).
