# GSD Quick: Neutrale Rollenlabels

## Ziel
In UI und API-Daten sollen Rollen neutral angezeigt werden. Rollen-Codes und Berechtigungen bleiben unveraendert.

## Scope
- Zentrale Frontend-Rollenlabels neutralisieren.
- `role_definitions.label_de` per neuer Migration fuer bestehende Daten korrigieren.
- Sichtbare Texte mit "Leader" auf neutrale Formulierungen umstellen, wo sie Rollen/Ansprechpartner anzeigen.
- Fokus-Tests und Migration anwenden.

## Nicht im Scope
- Keine Aenderung am Rollenmodell.
- Keine Anpassung an externe fansub.de-Freiformrollen.
- Keine Capability-Aenderung.
