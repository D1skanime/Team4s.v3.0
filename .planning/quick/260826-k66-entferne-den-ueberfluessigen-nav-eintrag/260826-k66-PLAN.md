<objective>
Remove the redundant "Capabilities" entry from the admin rights-module main navigation
(`ADMIN_NAV_LINKS` in `AdminMainNav.tsx`). Since Phase 138 (Sketch 005, D-01/D-08,
2026-08-24), `/admin/role-capabilities` is no longer an independent admin area — it is a
server-side `redirect()` to `/admin/roles`, where the Standardrechte-Matrix now lives as
the second tab ("Standardrechte") next to "Inhaber". The main nav currently still renders
two links ("Rollen" and "Capabilities") that both lead to the same destination, which
confused the user during live use.

Purpose: Eliminate the duplicate/confusing nav entry without touching the still-functional
redirect route that legacy bookmarks depend on.
Output: Updated `AdminMainNav.tsx` (5 links instead of 6) and updated
`AdminMainNav.test.tsx` (asserts Capabilities is absent, keeps coverage for the remaining
links and existing nested-route / hidden-outside-module test cases).
</objective>
