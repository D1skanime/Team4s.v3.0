## Cross-Phase Integration Finding

The review queue is wired across backend and frontend: the source implements `view=own` and serializes `allowed_types`. The canonical OpenAPI contract is stale:

- `ReleaseReviewView` at `shared/contracts/openapi.yaml` only lists `open` and `history`.
- `ReleaseReviewCounts` omits `allowed_types`.

This is documentation/contract drift, not a runtime outage, but it conflicts with the v1.4 contract-alignment and final-gate intent. It must be corrected and contract-tested before a clean milestone closure.
