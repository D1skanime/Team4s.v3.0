Canonical source for the extraction, verified at `frontend/src/app/admin/users/[id]/UserDetailPageClient.tsx:57-81`:

```typescript
function statusVariant(status: string): 'success' | 'warning' | 'danger' | 'neutral' {
  switch (status) {
    case 'active':
      return 'success'
    case 'pending':
      return 'warning'
    case 'disabled':
      return 'danger'
    default:
      return 'neutral'
  }
}

function statusLabel(status: string): string {
  switch (status) {
    case 'active':
      return 'Aktiv'
    case 'pending':
      return 'Ausstehend'
    case 'disabled':
      return 'Deaktiviert'
    default:
      return status
  }
}
```

Required exported names in the new file (per D-01, verbatim): `appUserStatusVariant`,
`appUserStatusLabel`. Fallback for unknown input: variant `'neutral'`, label = raw input value
(NOT a fixed fallback word) — this matches `getFansubLinkTypeLabel` in `fansub-labels.ts:32-34`,
not `getFansubMediaCategoryLabel`'s fixed-word fallback.

`Badge` from `@/components/ui` accepts `variant?: 'neutral' | 'success' | 'warning' | 'danger' |
'info' | 'muted'` (`frontend/src/components/ui/Badge.tsx:6-9`) — the helper's 4-value return type
is a subset, no type mismatch at any call site.
