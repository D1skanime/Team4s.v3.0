<objective>
Close GAP-12 from `164-UAT.md`: newly imported episodes get an episode type derived from the
anime's own type (tv->episode, ova->ova, ona->ona, movie->movie, special->special, else->episode)
instead of always hardcoding `'episode'`.

Purpose: The 2026-09-18 live UAT found that importing episodes for `11eyes: Pink Phantasmagoria`
(an OVA) left every episode typed as `'episode'`, requiring manual correction. `anime.type` is
already known at import time and already carries the correct value (`ova`) -- it was simply never
consulted.

Output: `applyReleaseNative` looks up `anime.type`, maps it to an `episode_types.name`, and uses
that instead of the literal `"episode"` string for every newly-created episode in that apply
transaction. Manually-typed episodes (`episode_type_source='manual'`) remain untouched, per the
existing `COALESCE(episode_type_id, ...)` update-branch behavior. No historical data changes.
</objective>
