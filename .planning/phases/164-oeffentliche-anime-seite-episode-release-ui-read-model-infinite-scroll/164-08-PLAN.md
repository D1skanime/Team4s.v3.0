## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DB row (`media_assets.file_path`, `fansub_groups.logo_url`) -> public JSON `logo_url` | Server-controlled data (admin-uploaded logo paths / admin-entered URL strings), not user input, but rendered as an `<img src>` on a public, unauthenticated page |
| DB row (`release_versions.title`, episode title, group names) -> public JSON `release_name` | Server-controlled data, rendered as plain text on a public, unauthenticated page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-164-13 | Tampering | `episode_version_public_query.go` / `release_detail_public_repository_helpers.go` logo URL builder | mitigate | The new expression only ever emits a fixed `/api/v1/media/files/` prefix plus a regex-derived basename of a server-controlled `media_assets.file_path` value (never client input), or the pre-existing `fansub_groups.logo_url` column verbatim -- no new user-controllable input reaches this expression, so no new injection/traversal surface is introduced. |
| T-164-14 | Information Disclosure | `release_name` computed field | accept | The computed default only recombines already-public data (episode title, group names, version label) already served by this same endpoint elsewhere in the response; no new data exposure. |
| T-164-15 | Denial of Service | `titleEnteredByGroupSQL`'s `NOT EXISTS` subquery against `release_variants` | accept | Bounded by the same `release_version_id` already scoped by the outer query's existing joins/indexes (`idx_release_variants_version`); adds one correlated subquery per row already being returned, no unbounded scan. |
