<objective>
Fix the one confirmed, narrow pre-existing gap 177-RESEARCH.md identified (Research Focus 3 /
Open Question 3): `ListReleaseVersionImagesCursor` — the query backing `ReleaseGallery.tsx`'s
`revealAll()` "load more" button — is missing the `mf_display` JOIN that its sibling query
(`imagesQuery()` in `release_detail_public_repository_helpers.go`, used for the SSR-initial page)
already has correctly. Per D-24 (user decision, 2026-10-09), this is fixed in this phase as a
clearly scoped, independently testable addition, not silently bundled or deferred.

Purpose: Without this fix, images loaded via "Weitere Bilder anzeigen" would never progressive-load
(Plan 177-04's new D-03 feature) — they would always render at original-resolution immediately
instead of display-first, unlike every other image on the same page.
Output: One additive `LEFT JOIN` + one additive `SELECT`/scan field in the existing cursor query,
plus a repository test proving both the new DisplayURL population and the unchanged visibility
predicate.
</objective>
