Close out the phase's remaining frontend gaps now that the backend `known_for` aggregate (Plan
132-01) and the consolidated viewer seam (Plan 132-03) exist: make `MemberProfileHero` a pure
reader of the server-authoritative `known_for` field, give visible profiles real SEO metadata,

`deriveKnownForFromPublicProfile` aggregating only the FIRST paginated project page) is fixed at

`Date.now()` mid-render inside an SSR-reachable tree, the canonical hydration-mismatch
anti-pattern.
Output: `MemberProfileHero.tsx` reading `profile.known_for`; `deriveKnownFor.ts` trimmed to its
still-used `KnownForResult` type only; member-specific `generateMetadata` output; one
`referenceNow` value threaded from both `page.tsx` and `OwnHiddenProfilePreview.tsx` through
`MemberProfileContent` into `LatestContributionsSection`.
