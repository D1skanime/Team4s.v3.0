page). Per `192-CONTEXT.md`'s `<addendum_2026-11-04b>` Befund-26 decision, this plan gives them a

NOT a repo-wide migration of the ~941 other raw filter/rgba/color-mix occurrences elsewhere in the
frontend (those are pre-existing, untouched by this phase, and explicitly out of scope).

Purpose: treat visual effects with the same token discipline already applied to spacing/radius/
breakpoints, so a future composite block reaches for a named effect token instead of inventing a new
raw `rgba()`/`blur()` literal.

file; a new "Grundlagen/Effekte" Storybook page; a phase-scoped guard test; `docs/FRONTEND_ARCHITEKTUR.md`
documents the rule.
