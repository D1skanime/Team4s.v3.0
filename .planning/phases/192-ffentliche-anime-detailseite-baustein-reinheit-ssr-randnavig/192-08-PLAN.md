<objective>
Fix Live-UAT-Befund 24: `Stack`/`Cluster`'s `gap` prop and `SplitLayout`'s `firstColumnWidth` prop
currently take raw space-scale numbers (`gap="2"`) or a free CSS-length string
(`firstColumnWidth="200px"`) directly from call sites — exactly the "size instead of purpose" naming
style the project's design-token discipline forbids everywhere else (space/radius/breakpoint tokens
are all purpose- or scale-named, never a bare magic number chosen per call site). This plan converts
both props to named purpose enums, backed by new CSS custom properties in `layout.css` that map onto
the unchanged underlying `--space-N` / `--media-frame-poster-width*` scale, and re-points the four
call sites this phase already touched (`AnimeDetailHero.tsx`, `FansubGroupPicker.tsx`,
`FansubVersionBrowser.tsx`, `ReleasePreviewRow.tsx`) at the new names.
