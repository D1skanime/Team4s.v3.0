| Browser -> `/api/v1/anime/:id/group/:groupId/members/:memberSlug` | Unauthenticated public GET; anime/group/memberSlug are attacker-controlled path params |
| Repository -> Postgres | Parameterized queries only; predicate constants are fixed Go string literals, never built from request input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-157-01 | Information Disclosure | countEpisodes query | mitigate | Reuses `projectMemberPublicNotePredicate`/`projectMemberPublicMediaPredicate`/`projectMemberUserIDsCTE` verbatim (Task 1) so a non-public note/media can never leak into the new count; proven by the Episode-D fixture case in the integration test |
| T-157-02 | Tampering | SQL construction | accept | Predicate constants are fixed Go string constants concatenated at compile time, never built from `c.Param`/`c.Query`; animeID/groupID/memberID reach the query only as `$1`/`$2`/`$3` bound parameters (unchanged existing pattern) |
| T-157-03 | Denial of Service | one additional QueryRow per GetSummary call | accept | Same cardinality class as the three existing counts on an already-indexed join path; no new N+1 or unbounded query introduced |
| T-157-SC | Tampering | package installs | n/a | No new npm/pip/cargo dependency introduced in this plan |
</threat_model>
