<objective>
Close GAP-02: at 394px viewport width, `RoleCapabilityImpactPreviewModal` — the CAP-09/D-18/D-19
safety gate shown before every role-to-capability mutation — clips one of its five impact metrics
out of the visible area and forces horizontal scrolling to reach the decision-relevant "NACHHER"
and "GRUND" columns of the per-user impact table.

Purpose: An admin must never confirm a global role-capability change without seeing every metric
and every user's before/after impact. Blind confirmation on narrow viewports defeats the whole
point of the impact-preview gate (D-18).

Output: A responsive metrics row that stacks to guarantee all 5 counts are visible, and a
narrow-width per-user Card list (replacing the horizontally-scrolling table only below 759px,
matching the existing `RoleHoldersTable.tsx` responsive pattern) that surfaces vorher/nachher/Grund
without scrolling. Desktop rendering is byte-for-byte unchanged.
</objective>

```typescript
function useIsMobile(): boolean {
  const [isMobile, setIsMobile] = useState(false)
  useEffect(() => {
    if (typeof window === 'undefined') return
    const media = window.matchMedia('(max-width: 759px)')
    const onChange = () => setIsMobile(media.matches)
    onChange()
    media.addEventListener('change', onChange)
    return () => media.removeEventListener('change', onChange)
  }, [])
  return isMobile
}
```
Usage: `if (isMobile) { return <Card variant="compact">...</Card> per row }` else render the
