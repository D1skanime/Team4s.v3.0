Wire D-22 ("Impact Preview auch bei Rollenzuweisung/-entzug") into the canonical Benutzer-in-Gruppe-Editor
(`UserGroupRightsTab.tsx`, built by Plan 138-06/08). Per D-11, a group's roles and its effective rights are

no new backend, only the frontend consumption + the preview-first gate D-18/D-20 require).

individual role changes exactly as it does to CAP-09's role→capability changes.

missing `setFansubGroupMemberRole` frontend consumption function (the mutation itself has existed and been
live in the backend since before this phase; it was simply never called from any frontend surface today).
