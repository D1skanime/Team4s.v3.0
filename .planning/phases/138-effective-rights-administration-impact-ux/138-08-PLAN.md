1. Trigger: `Button variant="secondary"` "Recht entziehen" on a capability row, only rendered when the
   capability is currently effective (`state.allowed === true`) for this user.
2. Step 1 (Modal size `md`): title "Recht entziehen: {Capability-Label}"; body = the locked D-16 template
   ("Dieses Recht wird aktuell gewährt durch: {Liste}. Das Entfernen nur einer dieser Rollen würde das
   Recht nicht vollständig entziehen. Empfohlen: Persönliche Abweichung für diesen Benutzer in {Gruppe}
   setzen.") listing every source from `state.granting_roles[]`/`state.specialized_grants[]`. If a source
   is Contribution-Role-only (see 138-RESEARCH.md Pitfall 5 — a role code that is `encoder`/`translator`/
   `timer`/other Contribution-context-only role) that source must be flagged inline as "kann durch eine
   persönliche Abweichung nicht entzogen werden" — this plan does NOT need to newly discover which roles
   are Contribution-only; treat any `granting_roles` entry that is not a known `fansub_group`-context role
   per `permissions.IsKnownFansubGroupRole` (already available) as this flagged case, and render the
   caveat inline next to it, never silently omitted.
3. Step 2 (same modal, no navigation): recommendation sentence + honest post-state preview ("Nachher:
   {Capability} nicht mehr erlaubt" OR, if a Contribution-Role-flagged source remains, "Nachher:
   {Capability} weiterhin erlaubt durch {andere Quelle}"). Confirm: `Button variant="danger"` "Recht
