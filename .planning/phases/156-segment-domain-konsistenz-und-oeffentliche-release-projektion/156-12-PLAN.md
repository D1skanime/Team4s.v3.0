<objective>
Build the data model and repository-layer foundation for GAP-01 (Segment-Contributors as an
explicit subset of the Origin-Release-Contributors, per `156-UAT.md`): a new join table storing
ONLY which people worked on a segment (never their role), a validated write path that rejects
anyone who is not currently an effective contributor of the segment's Origin, and an atomic
same-transaction cleanup when an admin changes a segment's Origin. Also extends the single
central `permissions.SegmentCreditRoleCodes` catalog with `editor`/`quality_checker` (role catalog
only -- the actual "only appears if explicitly selected" behavior is Plan 156-13's job).

Purpose: Everything downstream (public projection intersection in 156-13, admin UI in 156-14)
depends on this table existing, this validation being correct, and the Origin-change cleanup
being atomic. Getting this layer right first avoids rework in the plans that build on it.

Output: Migration 0162, extended role catalog, new `theme_segment_contributors.go` repository
file, and an atomicity fix to `theme_segment_origin.go`'s `SetThemeSegmentOrigin`.
</objective>
