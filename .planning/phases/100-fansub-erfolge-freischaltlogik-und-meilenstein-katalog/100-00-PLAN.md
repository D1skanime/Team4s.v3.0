<execution_protocol>
## Required Loop

For each achievement:

1. **Discuss** - decide when the achievement is selectable, locked, or hidden.
2. **Document** - update this plan/context with the rule decision if it changes.
3. **Implement** - change only the files required for that achievement rule.
4. **Test** - run focused frontend/backend/contract checks for that rule.
5. **Review visually** - for UI-affecting work, verify `/admin/fansubs/[id]/edit` and `/fansubs/[slug]`.
6. **Proceed** - start the next achievement only after the user accepts the current one.

Do not implement multiple rules in one pass unless the user explicitly says to batch them.
</execution_protocol>
