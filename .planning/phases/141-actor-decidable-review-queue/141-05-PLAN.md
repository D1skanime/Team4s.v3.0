<objective>
Build the "Wartet auf Fremdprüfung" lane (D01/D03/RQUE-03): a new, read-only sibling
component consuming `useReleaseReviewLane` (Plan 141-04) against `view: 'own'`, and wrap the
existing "Prüfungen" region in the global `Tabs` primitive (UI-SPEC Component Contract 1) so
the actionable queue and the actor's own pending submissions are two unmistakably separate
tracks -- different component idiom, different badge color, different label semantics, never
a shared numeric surface.

Purpose: this is D01's core UI requirement -- until this plan lands, an actor's own
submissions have no visible home at all in the admin UI (they simply do not appear, since the
backend now excludes them from the actionable queue as of Plan 141-02).

Output: `OwnPendingReviewsSection.tsx`, its test file, and `FansubEditSecondaryTabs.tsx`
wrapping both lanes in `Tabs` with independent, unfiltered badge counts and `?lane=queue|own`
URL sync.
</objective>
