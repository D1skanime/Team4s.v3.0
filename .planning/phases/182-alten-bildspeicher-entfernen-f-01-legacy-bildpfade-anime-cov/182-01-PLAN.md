<objective>
Remove the dead `hasV2AssetSchema`-gated legacy code branches across `anime_assets*.go`, migrate
every raw (non-V2-aware) reader of `anime.cover_image` to the shared V2-aware COALESCE helper so
D-01's Jellyfin-cover gap is closed everywhere, and retire the legacy `cover_image` mirror-write
machinery (`syncLegacyAnimeCoverImageV2`, the mirror-write in `removeAnimePosterAssetsV2`,
`ApplyProviderCover`'s `cover_image` write) so nothing except the real DB column still "knows
about" the legacy storage path. This is step 1+2 of `182-CONTEXT.md`'s "Zielbild und
Schrittfolge" and prepares the ground for Plan 182-02's column drop.

Purpose: After this plan, the `anime.cover_image` column is still present in the database but is
functionally inert — nothing reads it except the (soon to be trimmed) shared COALESCE helper, and
nothing writes it except historically. Plan 182-02 can then drop the column without touching
backend behavior.
Output: Legacy-branch-free `anime_assets*.go`, five migrated cover readers, a reusable
`OpenPhase182Postgres` throwaway-DB test helper, and real-Postgres regression tests proving D-01's
visible effect.
