Drop the now-functionally-inert `anime.cover_image` column via a reversible migration with a
pre-flight safety check (D-03), shorten the shared cover-resolution SQL helpers and the two
remaining inline duplicates of that COALESCE chain to match the post-drop schema, bring
`shared/contracts/*.yaml` documentation in line (D-02: field name and behavior stay, only the

D-03 is explicit that the column "wird in dieser Phase per Migration entfernt" (is removed by
migration in this phase), so this plan's scope includes the real apply-and-verify step against the
live database, not just authoring the migration file.

Purpose: Plans 182-01/182-02 already made `cover_image` write-dead and read-irrelevant everywhere
except the shared COALESCE helpers and two inline duplicates. This plan removes every remaining
code reference to the column (Task 2), then drops the column itself on the live database
(Task 3) — in that order, so there is never a window where live, running code queries a column
that no longer exists, nor a window where the column survives past this phase's completion.
Output: A new numbered migration pair, two trimmed SQL helper/query functions, corrected
OpenAPI/contract documentation, and the migration actually applied and verified against the live
`team4s_v2` database.
