drop is the exact inconsistency D-16 exists to avoid. This is a real behavioral gain for both ways
(neither has drag&drop today). File-type validation stays exactly as it is today for both: Weg 5
has none client-side (accept-hint + server-side only, per 180-RESEARCH.md); Weg 8 has a client-side
size check (20 MB max, `ReportFormMedia.tsx`'s `handleFileChange`) but no client-side type check —
neither gets new client-side validation as a side effect of gaining drag&drop; a dropped file runs
through the exact same `handleFileChange`/`onAssetUpload`/`onPendingUploadFileChange` callback a
picked file already does.
