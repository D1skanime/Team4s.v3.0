### D-10
Canonical (keep, extend if needed) (backend/internal/services/media_service_display_variant.go:102-114):
```go
// displayVariantFileName names the display variant after its original so several originals in
// one shared directory never overwrite each other's display file. ...
func displayVariantFileName(originalPath string, ext string) string {
	base := filepath.Base(originalPath)
	stem := strings.TrimSuffix(base, filepath.Ext(base))
	if stem == "" || stem == "original" { return "display." + ext }
	return stem + "_display." + ext
}
```
Duplicate to remove (backend/internal/handlers/admin_content_release_version_media_replace_display.go:18-20):
```go
func rvmReplaceDisplayPath(assetDir string, ext string) string {
	return filepath.Join(assetDir, "display."+ext)
}
```
Caller to redirect (backend/internal/handlers/admin_content_release_version_media_replace.go:269):
```go

```
