<objective>
Make `/api/v1/search` accept `tag`/`genre`-only queries without a search term, and make the tag/genre
filter match against any language name (not just the base name), while explicitly preventing the
fansub branch from silently returning every fansub group when no query term narrows it.

Purpose: This is Layer 2 (Nur-Filter-Suche, D-08/D-09/D-10/D-11) of the mandatory build order. It must
ship before Layer 3 (public display, plan 160-06) generates chip links pointing at this endpoint, and
it depends on plan 160-01's `tag_names`/`genre_names` tables for the D-10 multi-language match.
Output: `search.go`'s validation gate reordered and extended; `search_anime.go`'s genre/tag EXISTS
clauses extended; `search_repository.go`'s fansub dispatch explicitly empties instead of falling
through to an unfiltered `SELECT * FROM fansub_groups`.
</objective>
