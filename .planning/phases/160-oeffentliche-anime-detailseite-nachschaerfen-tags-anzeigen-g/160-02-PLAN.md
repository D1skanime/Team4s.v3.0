<objective>
Add admin-only backend CRUD for maintaining German tag/genre display names: a list endpoint (base name +
usage count + current German name) and a per-row upsert/clear endpoint, mirroring the existing
`ListTagTokens`/`ListGenreTokens` aggregation pattern but extended with the `tag_names`/`genre_names`
tables from plan 160-01.

Purpose: This is the write/maintenance side of Layer 1 (Mehrsprachigkeit, D-04/D-05). The new admin
frontend page (plan 160-03) depends on these endpoints existing with a stable contract.
Output: `GET /admin/tags/names`, `PATCH /admin/tags/:id/names/de`, `GET /admin/genres/names`,
`PATCH /admin/genres/:id/names/de`, all admin-gated, all parameterized SQL, with a real-Postgres
httptest suite proving status codes and response bodies.
</objective>
