```ts
const [cursorHistory, setCursorHistory] = useState<string[]>([]); // <- loses state on remount
const handleCursorChange = useCallback((nextCursor: string) => {
  setCursorHistory((prev) => [...prev, cursor ?? ""]);
  writeParams({ cursor: nextCursor }, false);
}, [cursor, writeParams]);
const handleCursorBack = useCallback(() => {
  if (cursorHistory.length === 0) return;
  const previousCursor = cursorHistory[cursorHistory.length - 1] ?? "";
  setCursorHistory((prev) => prev.slice(0, -1));
  writeParams({ cursor: previousCursor }, false);
}, [cursorHistory, writeParams]);
```

From `frontend/src/app/admin/anime/create/DiscoveryEntryCard.tsx` (existing, full file, 30 lines):
```tsx
export function DiscoveryEntryCard() {
  return (
    <Card variant="elevated" header={<div className={createStyles.resultsTitleBlock}>...</div>}>
      <p className={createStyles.resultsText}>Jellyfin-Bibliothek durchsuchen und offene Titel gezielt anlegen.</p>
      <Button href="/admin/anime/create/library" variant="primary">Bibliothek durchsuchen</Button>
    </Card>
  );
}
```
Root cause (verified against `frontend/src/components/ui/Card.tsx`/`ui.module.css`): `Card`'s outer
`<section>` is `display:grid; grid-template-columns: minmax(0,1fr)`, whose default `justify-items:
stretch` stretches EVERY direct grid-item child (the `<p>` AND the `Button`, both siblings in `children`)
to the full column width — this is what makes the button span the whole card, NOT an explicit
`fullWidth` prop (Button defaults to `fullWidth={false}`, confirmed in `Button.tsx`). `variant="elevated"`
adds `.cardElevated`'s box-shadow, which is what makes the card visually "highlighted" relative to its
plain-bordered `resultsPanel`-styled siblings.
`Card`'s `footer` prop renders inside `.cardFooter` (`display:flex`, NOT `display:grid`) — a flex row does
NOT stretch main-axis (width) sizing the way the grid does, so moving the Button into `footer` fixes the
full-width bug with zero new CSS. `.cardFooter` ALSO already has an existing `@media (max-width: 767px) {
flex-direction: column; align-items: stretch }` rule in `ui.module.css` (~line 1990), which makes a
footer's single child span full width automatically on narrow viewports — exactly the "full width only on
narrow screens" requirement, with zero new CSS needed.
