<objective>
Close a pre-existing IDOR-shaped gap (RESEARCH.md Pitfall 5): `PreviewEpisodeImport` currently accepts any
client-supplied `jellyfin_series_id` with zero ownership check against the target anime's connected
Jellyfin folders. Fix this fail-closed for every anime (not just the multi-folder case), and — because an
anime can now have more than one connected `jellyfin:` folder (D-05) — add a folder selector to the episode
import screen so an admin can pick which connected folder to import from, defaulting to the main folder.

Purpose: this closes the D-14 security gap immediately and independently of the rest of the phase, and
produces a shared, pure folder-enumeration helper (`jellyfin_source_folder_list.go`) that 165-07 (D-18
folder management on the edit page) reuses rather than re-implementing the same `source`/`source_links`
prefix-extraction logic a second time.
Output: fail-closed ownership guard in `PreviewEpisodeImport`; `EpisodeImportContextResult` extended with
an enumerated folder list; `EpisodeImportFolderSelector.tsx` wired into the existing import screen.
</objective>
