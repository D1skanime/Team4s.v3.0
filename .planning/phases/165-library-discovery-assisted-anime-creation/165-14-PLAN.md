<objective>
Fix GAP-07 (165-UAT.md): when an admin explicitly selects a second, additionally-connected Jellyfin
folder in the episode-import preview (D-14 selector, already wired in 165-04), the preview comes back
empty. Root cause: `loadEpisodeImportMediaCandidates` is always called with `contextResult.FolderPath`
(the anime's MAIN folder path) regardless of which `jellyfinSeriesID` was actually selected;
`enumerateJellyfinMediaSources` (jellyfin_media_source.go) then discards every episode whose path isn't
under that main-folder prefix, even though `listJellyfinEpisodes(ctx, jellyfinSeriesID)` already scoped
the fetch server-side to the SELECTED series (folder B), not folder A.

Purpose: makes the D-14 "Ordner-Auswahl bei mehreren verbundenen Jellyfin-Ordnern" feature actually
usable — today the selector exists in the UI but silently returns zero results, GAP-05 (also in this
gap-closure round, see 165-17) is what actually populates the two-folder state.
Output: `PreviewEpisodeImport` filters by the SELECTED folder's own path (fetched once via the already-
existing `getJellyfinSeriesByID`, not per-episode) instead of unconditionally reusing the main folder's
path; the existing ownership guard (`rejectUnownedJellyfinSeriesID`) is untouched.
</objective>
