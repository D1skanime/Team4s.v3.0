<objective>
Wire the existing Create-page controller to support the Discovery hand-off end to end: auto-adopt a
Jellyfin candidate from a `?jellyfin_id=` query param (reusing the existing, unmodified
`handleJellyfinCandidateAdopt` pipeline, D-08), prefill (never auto-run) the AniSearch search field with the
Jellyfin series name (D-09), branch the post-create redirect between the untouched manual path and the new
assisted path (D-10), and extract/extend the existing AniSearch conflict block into a real
"verbinden"/"neu anlegen" decision that fires at both the AniSearch-selection point (D-02) and the
save-time re-check from 165-03 (D-20).

Purpose: this is the single plan that touches the Create page's central state (`useAdminAnimeCreateController.ts`)
for every Discovery-related concern, avoiding a same-wave file conflict that would occur if this work were
split across two plans.
Output: `AniSearchDuplicateDecision.tsx` (new), `page.tsx`/`useAdminAnimeCreateController.ts`/
`createAniSearchControllerHelpers.ts`/`CreateAniSearchIntakeCard.tsx` extended additively.
</objective>
