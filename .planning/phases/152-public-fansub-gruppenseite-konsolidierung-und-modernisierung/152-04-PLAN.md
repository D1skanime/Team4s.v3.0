<objective>
Fix the media-thumbnail double-labeling accessibility defect (D3) and give `CATEGORY_TAG_CLASS`
compile-time exhaustiveness against the backend's category allowlist (C4), adding jest-axe coverage
for this component for the first time (D4). Independent file, independent of the History-artwork
migration and the backend query-flow plans (D09 file-ownership separation).

Purpose: `FansubGroupMediaBlock.tsx`'s clickable thumbnail `Button` carries `aria-label={title}` AND
its inner `next/image` carries `alt={title}` — both announce the identical string inside one
interactive control, which most screen readers surface as duplicated or conflicting accessible-name
content. Separately, `CATEGORY_TAG_CLASS: Record<string, string>` silently falls back to `tagOther`
for any unrecognized category with no compiler signal, unlike the backend's authoritative closed
allowlist in `fansub_media_review_handler.go`.
Output: `alt=""` on the inner image (Button's `aria-label` becomes the sole accessible name); a
`FansubMediaCategory` union type backing the lookup table; a new axe-covered test file for this
previously-untested component.
</objective>
