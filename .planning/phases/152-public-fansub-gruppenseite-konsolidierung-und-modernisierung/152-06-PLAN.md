composing five conditional sections (`storyAvailable`/`hasTeam`/`hasHistory`/`hasMedia`) and a
best-effort domain-projection fallback — none of that composition logic is currently tested.
Output: `page.tsx`'s domain-projection load as an explicit `try/catch`; new composition tests proving
each section's conditional rendering and the domain-projection failure fallback, using coarse,
Wave-2-migration-resilient assertions (heading/landmark presence, not internal badge/CSS class
details).
