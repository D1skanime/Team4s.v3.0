**Requirement:** PMCT-01, PMCT-02, PMCT-04, PMCT-05. **Depends on:** nothing (OpenAPI is the canonical source; contract-first per D-05).
**Goal:** `shared/contracts/openapi.yaml` becomes the single source of truth for the public profile contract — dedicated `PublicMemberMembership` + `PublicMemberProfileBackgroundImage` allow-list schemas (no internal permission/status/source fields), the four public enums complete and closed (incl. `next_tier` platinum, D-06), the one shared `ErrorResponse` envelope documented for the visible/hidden/missing/failure branches (D-03/D-04), and proven absence of `recent_*` in every `PublicMember*` schema.

**Read first:** `docs/api/api-contracts.md` (contract-first workflow; OpenAPI as source — the rule behind D-05), `130-CONTEXT.md` (D-01/D-03/D-04/D-05/D-06), and in `shared/contracts/openapi.yaml`: `MemberProfileMembership` (~L10685), `MemberProfileBackgroundImage` (~L10649), `PublicMemberBadge` (~L11458), `PublicMemberBadgeProgress` (~L11496), `PublicMemberProfileData` (~L11606), `PublicMemberCurrentProject` (~L11014), `PublicMemberLatestContribution` (~L11060), `ErrorResponse` (~L9435), `PublicMemberProfileEnvelope` (~L11433).

**Files**

**Steps**
1. **Dedicated public membership schema (D-01).** Add `PublicMemberMembership` = the allow-list of `MemberProfileMembership` MINUS `app_member_status`, `app_member_roles`, `historical_member_status`. Keep exactly: `fansub_group_id`, `fansub_group_name`, `fansub_group_slug`, `logo_url?`, `group_status`, `joined_year?`, `left_year?`, `is_current`, `roles` (→ `PublicMemberRole[]`, non-null), `has_historical_link`. Repoint `PublicMemberProfileData.memberships.items` → `PublicMemberMembership`. Leave the internal `MemberProfileMembership` schema untouched (still referenced by the internal edit surface). Delete the now-obsolete "app_member_status … are omitted" note from the memberships description (it currently lies because the referenced schema still carries those fields).
2. **Dedicated public background schema (D-01 media allow-list).** Add `PublicMemberProfileBackgroundImage` = `{ public_url }` only (DROP `source_original_url` — it is an edit-surface re-crop source, never a public display field). Repoint `PublicMemberProfileData.background_image` (currently `allOf: MemberProfileBackgroundImage`) → `PublicMemberProfileBackgroundImage`. Leave the internal `MemberProfileBackgroundImage` schema untouched. Confirm no other internal id/storage field is reachable from any public sub-schema (avatar is already `{ public_url }`).
3. **Complete + close the public enums (D-06).** Add `platinum` to `PublicMemberBadge.next_tier` → `enum: [bronze, silver, gold, platinum]` (mirrors `current_tier`'s `[entry, bronze, silver, gold, platinum]`). Verify and, where open, close for consistency: `PublicMemberBadgeProgress.next_tier` (align to the same tier enum, nullable), `profile_status` (`[active, historical, memorial]` — already present, verify), `PublicMemberLatestContribution.type` (`[text, media]`), `PublicMemberCurrentProject.contribution_status` (verify its enum matches the runtime value(s); keep it closed and consistent with the Go/TS union).
4. **One error envelope, documented (D-03/D-04).** Confirm the profile 200 references `PublicMemberProfileEnvelope` (`{data, viewer}`), projects 200 references `PublicMemberProjectsEnvelope`, and EVERY 404/500 on the public member profile + projects operations (path `/api/v1/members/{slug}` and its projects sub-path) references `ErrorResponse`. In the operation descriptions, state the contract explicitly WITHOUT introducing a body discriminator: visible→200; hidden AND missing→identical neutral 404 `{error:{message}}`; failure→500 `{error:{message, code?, details?}}`. Do NOT add any state/discriminator field (would risk making hidden distinguishable from missing — 128 lock).
5. **Recent_* parity (D-02, verify-only).** Grep every `PublicMember*` schema and assert NO `recent_media` / `recent_contributions` remain (Phase 129 removed them from the public DTO). No change expected — this step PROVES OpenAPI parity. Do NOT touch `MemberProfileRecentContribution` / any internal recent schema (still used by the internal edit surface).
