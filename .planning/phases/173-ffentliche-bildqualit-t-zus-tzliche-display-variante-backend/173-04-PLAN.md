<objective>
Give fansub logos, banners, and group-media uploads their own `/media/fansub/<group_id>/...`
namespace (D-09), add a `display` variant to both the logo/banner path (which has no existing
thumb/display analog today — `media_service.go`'s `SaveUpload` only ever wrote `original`) and the
group-media path (which already shares `generateRVMThumbnail` with release-version-media), and add
a permanent 301 redirect from the legacy `/api/v1/media/files/:filename` route to the new namespace
for assets that have been migrated (D-17).

Purpose: this is write path #4 from `173-RESEARCH.md` (split into 4a group-media / 4b logo-banner)
plus the namespace/redirect decisions (D-09/D-17) that specifically target fansub branding/media,
which today bypass the existing anime/profile/release-version namespace convention entirely and
are served through a different Go-backend route (`GET /api/v1/media/files/:filename`,
`cmd/server/main.go:451`) rather than the Next.js static `/media/[...path]/route.ts` file route.

Output: `media_service.go`'s `SaveUpload` takes a `groupID` parameter and builds namespaced paths
for fansub kinds; new uploads get a `display` variant; `ServeMediaFile` redirects migrated legacy
URLs.
</objective>
