Add a `display` media-file variant to the member-avatar and profile-background upload flows in
`app_profile.go`, and surface it as `display_url` (with fallback to the original) on the own-profile
read model.

separately in 173-06 because it also needs the D-15 true-original fix). Avatars/backgrounds

already INSERT a `variant='original'` row, confirmed by reading
`member_profile_own_repository.go:217-232`), so this plan follows that exact existing pattern
rather than inventing a new storage shape.

Output: `app_profile.go` writes a `display` media_files row for both avatar and background
uploads; `models.MediaAsset`/`models.MemberProfileBgImage` gain `DisplayURL`;
`member_profile_ensure_repository.go`'s `ensureProfileBase` query resolves it with a fallback to
the original.
