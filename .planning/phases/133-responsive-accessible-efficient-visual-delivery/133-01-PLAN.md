<interfaces>
No new production interface. `toHaveNoViolations(results: AxeResults): { pass: boolean; message: () => string }`
is the matcher shape `jest-axe` registers on Vitest's `expect` via `expect.extend()`. Downstream
plans call it as `expect(await axe(container)).toHaveNoViolations()` where `axe` is imported from
`jest-axe` directly in each test file (no wrapper needed beyond the global matcher registration
this plan provides).
