## Sampling Rate

- **After every task commit:** Run the focused backend package or frontend component test plus `git diff --check`.
- **After every plan wave:** Run affected backend packages and frontend Vitest, typecheck, and lint.
- **Before `$gsd-verify-work`:** Run migration Up/Down safety, full backend/frontend suites, build, contract checks, and live in-app-browser UAT when feasible.
- **Max feedback latency:** 120 seconds for focused task checks.
