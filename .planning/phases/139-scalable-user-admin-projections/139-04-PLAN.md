`FileSizeBytes` fields into a server-side grouped (Anime -> Projekt -> Release/Episode), filtered,
paginated projection with real media URL derivation — closing UADM-05. This plan has more existing

of the currently-broken empty PublicURL, while removing the fake `Berechtigung aktiv/fehlt` signal
(D19) at its source and keeping deep storage/technical diagnostics out of this view entirely (D18 —
reserved for a later, separate Metabase/reporting idea per D27, out of this phase's scope).

handler filter-param wiring alongside 139-03's contributions params (this plan is the second and
final plan to touch `admin_users_handler.go`'s filter-parsing block and
`admin_users_tab_repository.go`, hence its Wave-3 dependency on 139-03 for file-ownership

SELECT rvm.media_asset_id, COALESCE(mt.name, ma.mime_type, 'media'), COALESCE(ma.file_path, ''),
  ''::text /* PublicURL hardcoded empty */, 0::bigint /* FileSizeBytes hardcoded zero */,
  rvm.created_at::text, 'release_version:' || rvm.release_version_id::text /* D19: remove */
FROM release_version_media rvm JOIN media_assets ma ON ma.id = rvm.media_asset_id
LEFT JOIN media_types mt ON mt.id = ma.media_type_id
WHERE rvm.uploaded_by_user_id = $1 AND rvm.deleted_at IS NULL

<!-- Real PublicURL derivation convention to copy (admin_content_release_version_media.go:535-541) -->
func buildRVMPublicURL(storagePath string) string {
    rel := strings.TrimPrefix(storagePath, mediaStorageDir)
    rel = strings.TrimPrefix(rel, "/")
    rel = strings.ReplaceAll(rel, "\\", "/")
    return "/media/" + rel
}
