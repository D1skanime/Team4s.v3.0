<!-- URL-synced filter hook pattern to copy exactly (useClaimsListFilters.ts, full file) -->
useRouter/usePathname/useSearchParams; searchParams.get(field) ?? '' per filter; offset via
Number(searchParams.get('offset') ?? '0') || 0; writeParams(patch, resetOffset=true) merges over
current values via a new URLSearchParams(searchParams.toString()), deletes empty keys, sets
non-empty ones, resets offset to 0 unless resetOffset=false (used by handlePageChange); always
router.replace(query ? `${pathname}?${query}` : pathname, { scroll: false }), never router.push;
final `params` object built via useMemo keyed on every underlying URL-derived value (load-bearing —
prevents an infinite refetch loop in the consuming tab's own loadData useCallback).
