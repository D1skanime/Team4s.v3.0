<objective>
Relocate the Media + Metadata + Classification + JellyfinNotice + `episodeVersionEditorUtils` family of
shared, non-route-specific files out of `app/admin/episode-versions/[versionId]/edit/` (which is about to
be deleted, Plan 09) into a neutral `frontend/src/components/releaseEditor/` folder, per RESEARCH.md
Pitfall 4: these files are today a "hidden component library" living inside an admin ROUTE folder,
imported by both old pages AND 4 external files outside either route. `episodeVersionEditorUtils.ts` is
included in this plan (not a separate one) because `ReleaseVersionMetadataFields.tsx` imports form-state
helpers from it directly -- moving one without the other would break the relocated component immediately.
This is a pure relocation -- no behavior change, no logic edits, except extracting 2 small CSS fragments
so the moved files stop reaching into the (soon-deleted) admin page's `EpisodeVersionEditor.module.css`.

Purpose: make these components importable from a stable, routing-independent location before the old
admin route folder is deleted in Plan 09, and before the new `/releases/[versionId]/edit` page (Plans 05-07)
needs to import them.
Output: 20 files under `frontend/src/components/releaseEditor/`, both old pages' import lines updated (4
files: `EpisodeVersionEditorPage.tsx`, `useEpisodeVersionEditor.ts`, `workspace/page.tsx`, plus the moved
files themselves), 4 external files' import lines updated.
</objective>
