## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| slug route params -> public profile API | Untrusted slugs resolve to a Fansub profile and one project. |
| public profile DTO -> public link rendering | DTO fields become public URLs. |
| technical route -> metadata | Numeric route exposes canonical public identity. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-102-02-01 | Tampering | Pretty route slug resolver | mitigate | Match `fansubSlug` profile and exact `anime_slug`; `notFound()` on mismatch. |
| T-102-02-02 | Information Disclosure | `PublicFansubProject` DTO | mitigate | Add only `anime_slug`; reuse existing public profile visibility query and no new endpoint. |
| T-102-02-03 | Repudiation | route compatibility | accept | This is public read-only routing; no mutation or audit event is introduced. |
</threat_model>
