## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public story HTML -> React rendering | Sanitized rich text is rendered into a public page. |
| project contributors API -> member links | Public contributor DTO controls displayed names, roles, and optional links. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-102-04-01 | Tampering | `StorySection` rich text | mitigate | Reuse `RichTextRenderer`/existing sanitized story seam; do not introduce raw HTML rendering. |
| T-102-04-02 | Information Disclosure | `ProjectMemberRows` roles | mitigate | Render only project-scoped `role_labels` returned by `getGroupContributors`. |
| T-102-04-03 | Spoofing | member link targets | mitigate | Link only when existing `member_slug` exists; otherwise non-link row. |
</threat_model>
