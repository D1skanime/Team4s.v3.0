# Phase 102 - UI Design Contract

> Visual and interaction contract for the public Fansub project detail page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none - use the existing Team4s UI system |
| Preset | not applicable |
| Component library | Team4s custom primitives in `frontend/src/components/ui` |
| Icon library | `lucide-react` |
| Font | `Inter, "Segoe UI", system-ui, sans-serif` via `--font-sans` |

Source: `docs/frontend/ui-system.md`, `frontend/src/styles/globals.css`, `frontend/src/components/ui`, `102-CONTEXT.md`, `102-RESEARCH.md`.

Design-system gate:
- `components.json` is absent and shadcn is not initialized.
- Do not initialize shadcn in this phase because the project already has a documented custom UI system and reusable primitives.
- Use `Button`, `Card`, `Badge`, `SectionHeader`, `EmptyState`, `LoadingState`, and `ErrorState` before adding local equivalents.
- Local CSS is allowed only for the public Fansub project composition, glass hero, same-Fansub navigation placement, story flow, and project-member row adaptation.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, focus offsets, compact row separators |
| sm | 8px | Badge gaps, chip gaps, compact inline groups |
| md | 16px | Default card padding, member row gaps, section inner rhythm |
| lg | 24px | Hero body padding, section padding, card-to-card gaps |
| xl | 32px | Major section gaps, flowing page section rhythm |
| 2xl | 48px | Desktop hero-to-content and large section breaks |
| 3xl | 64px | Page bottom padding and major public-page breathing room |

Exceptions:
- `12px` is allowed for existing Team4s primitive padding and compact gaps where already established.
- Interactive touch targets must stay at least `44px` high on mobile and tablet portrait.
- Existing control heights remain `36px`, `44px`, and `52px` from `--control-height-sm/md/lg`.

Layout contract:
- Page max width: project content uses `min(1200px, 100% - 40px)` or the existing public Fansub page width when extracting shared composition.
- Hero remains full-bleed only for the blurred backdrop; readable content stays centered in the glass hero card.
- Section flow uses one vertical page rhythm. Do not reintroduce the section nav/jump list.
- Avoid card-in-card for the project body. Cards are allowed for repeated release rows or inherited UI primitives only.

## Typography

Use exactly these four public-page text sizes for new or touched Phase 102 UI. Existing global primitives may keep their internal CSS where reused unchanged.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 700 | 1.4 |
| Heading | 20px | 700 | 1.2 |
| Display | 28px | 700 | 1.15 |

Typography contract:
- Only `400` and `700` are allowed for new local Phase 102 text styles.
- Do not scale font size with viewport width in new CSS.
- Letter spacing is `0` for body, member names, release labels, and hero title. Existing uppercase eyebrows may use their current UI-system letter spacing.
- Hero title is the Anime title; Fansub group name appears as eyebrow/context text, not as a competing H1.
- German UI text must use correct umlauts: `Zurück`, `öffentlich`, `Mitwirkende`, `vollständig`, `für`.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--surface-canvas` `#f6f4ef` | Public page canvas and section flow |
| Secondary (30%) | `--surface-card` `#ffffff` | Glass/card surfaces, member rows, release rows |
| Accent (10%) | `--accent-primary` `#5f84dd` | Reserved elements listed below |
| Destructive | `--color-error` `#dc3545` | Destructive actions only; no destructive actions are planned in this phase |

Accent reserved for:
- Primary public project links from `/fansubs/[slug]`.
- Hero same-Fansub previous/next controls when present.
- Clickable member names and chevrons using the public Fansub member row pattern.
- Coop group links in `Coop mit ...`.
- Focus states inherited from global primitives.

Additional visual tokens:
- `--accent-deep` `#185fa5` may remain for hero stat numbers and the existing top hero line.
- `--ui-line` `#82122c` remains a fine divider/underline color, not a general accent fill.
- Hero backdrop may use the existing blurred banner scrim only when an actual Anime/Fansub image is available.
- Do not introduce a new dominant palette, a purple/blue gradient theme, or decorative orb backgrounds.

## Visual And Interaction Contract

### Route Identity

- Public target route: `/fansubs/[fansubSlug]/fansubprojekt/[animeSlug]`.
- Compatibility route: `/anime/[id]/group/[groupId]` remains available and exposes canonical metadata to the pretty route when slugs are known.
- Public Fansub project cards must prefer the pretty route once `anime_slug` is available.
- Do not build client-only slugification as the source of truth.

### Hero

- The project detail hero visually relates to `FansubHeroSection`: blurred real image backdrop, centered glass hero card, sharp banner/poster media, compact stat row, and calm public-site spacing.
- The hero content order is: breadcrumb/back context, glass card, Fansub eyebrow, Anime H1, project stats, optional coop hint, same-Fansub project navigation.
- `Coop mit ...` lives inside or directly adjacent to the glass hero card, not in the further-project navigator.
- Coop links list only other participating groups and link to `/fansubs/[slug]`.
- Same-Fansub previous/next controls belong to the glass hero card edge on desktop/tablet; mobile collapses them below the card content as full-width or two-column touch targets.
- Hide previous/next navigation when there are no same-Fansub neighbors.

### Story

- Render exactly one collapsible story block.
- Use the existing public story/collapsible reading behavior as the visual baseline.
- Do not use the public Fansub multi-story archive/modal pattern.
- Hide the story section entirely if no public project story exists unless a later slice explicitly needs a local empty state.

### Members

- Replace the current local card grid target with the public Fansub member row language.
- Section title is `Mitwirkende am Fansub-Projekt`.
- Show only roles for this Fansub project.
- Member entries are clickable when an existing safe member slug exists; link to `/members/[slug]` as the current safe fallback.
- Do not create the deferred project-scoped member contribution route in this phase.
- Empty project-member data omits the section by default.

### Releases

- Remove the standalone latest-release highlight.
- Keep the existing release list structure conservative.
- Retitle the release section to `Releases zum Fansub`.
- Keep loading and error states scoped to the release list, not the whole page.
- The `Mehr laden` action remains a normal `Button` and must not shift the list layout.
- Audit release label data for D-18 before accepting the release slice.

### Removed Sections

- Remove the section nav/jump list.
- Remove global empty summary.
- Remove standalone OP/ED/Middle section from this page.
- Remove standalone Medien section from this page.
- Do not delete APIs or media ownership structures as part of these UI removals.

### Responsive Checks

- Desktop check: `>= 1200px`, hero card has embedded left/right same-Fansub controls and no page-edge floating controls.
- Tablet portrait check: `768px-1024px`, hero card does not become cramped; navigation remains near the hero and touch targets stay at least `44px`.
- Mobile check: `< 768px`, hero stacks media, title, stats, coop hint, and navigation without text overlap or horizontal scroll.
- Each accepted slice must be checked live at `http://127.0.0.1:3000`; supporting Playwright screenshots are acceptable but do not replace live shared-flow review.
