<objective>
Remove the third parallel, broken color mapping in the frontend (`categoryForRole()`, which since
commit `84a38c0f` returns a raw hex `color_key` value instead of a semantic category, per ROADMAP
Phase 148 Ausgangsbefund and CONTEXT decision #3), and decouple `presentationForRole()` so an
unrecognized `icon_key` no longer silently discards a valid `color_key` (decision #5). Migrate the
six `categoryForRole()` call sites - `ProjectMemberHero`, `ProjectMemberReleaseCard`,
`MemberCurrentProjectsSection` (2 call sites), `ContributionCard`, and
`me/projects/[animeId]/group/[fansubGroupId]/page.tsx` - onto `data-role-code={role.code}` (real
code) + `data-color-key={presentationForRole(rows, role.code).colorKey}` (real bounded hex or
`neutral`).

Purpose: today `data-role-code` on these six surfaces literally contains a hex string
(e.g. `data-role-code="#7b3c4e"` on the live project-member page, per ROADMAP), which matches no
CSS selector and is not a role code. This plan restores the correct semantic/color split that the
rest of the app already uses.

Output: `roleCatalog.ts` with `categoryForRole` removed and `presentationForRole` decoupled; six
consumers correctly wired; `MemberCurrentProjectsSection.module.css`'s twelve dead
`[data-role-code='<code>']` color selectors removed (its `.roleChip` now reads color from
`--role-accent` alone, matching the `data-color-key` seam every other surface uses).
</objective>

export type RoleColorKey = (typeof ROLE_COLOR_KEYS)[number]

export type BoundedRoleColorKey = RoleColorKey | typeof NEUTRAL_ROLE_COLOR_KEY
export const ROLE_CATALOG_CHIP_CLASS = 'role-catalog-chip'
export type RolePresentation = { colorKey: BoundedRoleColorKey; iconKey: string }
const ICON_KEYS = new Set(['crown','image','wrench','languages','check','film','user'])
const neutral: RolePresentation = { colorKey: NEUTRAL_ROLE_COLOR_KEY, iconKey: 'user' }
export function getRole(rows, code): RoleDefinitionOption | undefined
export function labelForRole(rows, code): string
export function orderForContext(rows, context): RoleDefinitionOption[]
function boundedColorKey(value): BoundedRoleColorKey   // lowercases + validates against ROLE_COLOR_KEYS, else 'neutral'
export function presentationForRole(rows, code): RolePresentation, current body:
  const role = getRole(rows, code)
  if (!role || !role.icon_key || !ICON_KEYS.has(role.icon_key)) return neutral   // to change
  return { colorKey: boundedColorKey(role.color_key), iconKey: role.icon_key }
export function categoryForRole(rows, code): string, current body (to delete entirely):
  return getRole(rows, code)?.color_key?.trim().toLowerCase() || 'other'
