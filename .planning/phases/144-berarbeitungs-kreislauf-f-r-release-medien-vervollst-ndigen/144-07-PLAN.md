`source_revision`/`status` fields on `ReleaseReviewQueueItem` (queue/list badge — no new fetch

helper.
Output: a warning-variant "Überarbeitet" badge + context line on the detail page; a compact
badge on queue rows; tests proving both renderings and the "no duplicate status-formatting logic"
invariant.
