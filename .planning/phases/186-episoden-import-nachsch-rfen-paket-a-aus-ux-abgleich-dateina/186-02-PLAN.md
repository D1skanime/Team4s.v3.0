<objective>
Replace the bug-prone handrolled `Exx` fallback regex (which misreads CRC tags like `[E61CA0BA]`
as episode 61) with `github.com/nssteinbrenner/anitogo` behind a new, swappable
`services.ReleaseFilenameParser` interface -- mirroring the existing `Mailer`/`SMTPMailer`/
`NoopMailer` seam in `backend/internal/services/mailer.go`. Only the innermost fallback step
changes; Jellyfin-metadata priority and the `SxxExx` regex path are untouched, which is what makes
all 15 real DB filenames provably regression-safe (they all match `SxxExx` and never reach the
replaced code path at all).

Purpose: fix Finding #15 (CRC-as-episode-number bug) without hand-patching three regexes, using a
maintained third-party parser behind a thin, testable, swappable boundary.
Output: a new `services.ReleaseFilenameParser` interface + anitogo-backed implementation, wired
into the preview pipeline, with two mandatory test groups (new raw-filename cases, and an
old-vs-new regression comparison against real data).
</objective>
