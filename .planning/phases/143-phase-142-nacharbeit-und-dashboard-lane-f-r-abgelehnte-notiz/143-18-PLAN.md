<objective>
Close the frontend rendering half of UAT-02: consume plan 143-17's new `has_own_rejected_notes` field
to give the member-project release list a real third visual state ("Überarbeitung nötig") instead of
collapsing a rejected-only release into the same "Offen" badge as a release nobody has touched at
all, and stop downgrading that release's action button to `secondary` prominence.

Purpose: `isDone()`'s two-state boolean (`has_own_notes || has_own_media`) is correct for the
open/done COUNT and FILTER (a needs-rework release genuinely is not done yet), but the per-row Badge
and button-prominence logic need a third label so a reviewer/contributor can tell "never started"
apart from "rejected, needs rework" at a glance.
Output: `page.tsx`'s per-row badge/button logic reads the new field; `isDone()` itself, the
open/done counters, and the "Offen"/"Erledigt" filter predicate are NOT touched (they already produce
the correct classification per Kriterium 5 — this plan only changes what is displayed, not what is
counted).
</objective>
