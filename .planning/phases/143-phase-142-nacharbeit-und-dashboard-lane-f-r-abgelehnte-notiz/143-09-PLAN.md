`attachPendingGroupMediaReviewAttention` (currently ~34 lines) runs:
```sql
SELECT fgm.group_id, fg.name, COUNT(*)
FROM fansub_group_media fgm
JOIN media_assets ma ON ma.id = fgm.media_id
JOIN fansub_groups fg ON fg.id = fgm.group_id
JOIN review_statuses rs ON rs.id = ma.review_status_id
WHERE fgm.deleted_at IS NULL AND rs.code = 'in_review'
AND (fg.logo_id IS NULL OR ma.id <> fg.logo_id) AND (fg.banner_id IS NULL OR ma.id <> fg.banner_id)
GROUP BY fgm.group_id, fg.name
```
then for each row calls `h.permissionSvc.CanForFansubGroup(ctx, actor, permissions.ActionFansubGroupEdit, item.FansubGroupID)`
— WRONG action per Criterion 3; must become `permissions.ActionReviewImageDecide` (already the
correct review action used for `release_version_media` review decisions elsewhere in this same
handler, and via `CanForFansubGroup` it is a valid generic Action check).

`attachPendingReleaseReviewAttention` (currently ~70 lines) runs a query grouping
`release_review_lifecycle_sources` by `(version_group.fansub_group_id, anime.id)` with the
self-exclusion predicate (quoted below), then for EACH resulting row (which can repeat the same
`fansub_group_id` across multiple anime rows) calls
`h.permissionSvc.ResolveReviewGroupAuthorization(ctx, actor, item.FansubGroupID)` — this is the
N+1 that needs per-group memoization (cache the `ResolveReviewGroupAuthorization` result keyed by
`FansubGroupID`, matching `attachPendingClaimAttention`'s `allowedByGroup := make(map[int64]bool)`
memoization shape, but caching the whole authorization result object here since two separate
booleans are read from it per row).

Self-exclusion predicate to preserve VERBATIM and relocate to become the ONLY copy in the codebase
(source: `dashboard_me_handler.go`, current location inside `attachPendingReleaseReviewAttention`'s
SQL):
```sql
WHERE lifecycle.review_state = 'pending'
  AND lifecycle.submitter_app_user_id <> $1
  AND NOT EXISTS (
    SELECT 1 FROM member_claims own_claim
    WHERE own_claim.app_user_id = $1
      AND own_claim.claim_status = 'verified'
      AND own_claim.member_id = lifecycle.submitter_member_id
  )
```

`release_review_query_repository.go` (already correct, do not change):

```go
type ReleaseReviewQueryRepository struct { db releaseReviewQueryDB }
func NewReleaseReviewQueryRepository(db releaseReviewQueryDB) *ReleaseReviewQueryRepository
```

Memoization pattern to copy exactly (already correct today, from
`attachPendingClaimAttention`):
```go
allowedByGroup := make(map[int64]bool)
for _, candidate := range candidates {
	allowed, checked := allowedByGroup[candidate.FansubGroupID]
	if !checked {
		result, err := h.permissionSvc.CanForFansubGroup(ctx, actor, <action>, candidate.FansubGroupID)
		if err != nil { return err }
		allowed = result.Allowed
		allowedByGroup[candidate.FansubGroupID] = allowed
	}
	if !allowed { continue }
	// append
}
```
