**Verbindliche Vorgabe aus der Planpruefung — vor Task 1 lesen.**

`not-found.tsx` ist heute eine **Server Component** (keine `'use client'`-Direktive), und
`OwnHiddenProfilePreview` ist eine Client Component (`'use client'`). Daraus folgt:

- `next/dynamic(..., { ssr: false })` ist in einer Server Component **nicht zulaessig** —
  Next.js lehnt das ab. Die illustrative Zielform oben ist deshalb erst nach dem Setzen einer
  Client-Grenze gueltig.
- `React.lazy` + `<Suspense>` ist in einer Server Component ebenfalls kein Ersatz: beides sind
  Client-Mechanismen.
- Der Fallback-Grund im Task-Text ("Friktion im Testumfeld") ist damit **nicht** der
  entscheidende: die Server/Client-Grenze ist es.

Zulaessige Wege, Praeferenz in dieser Reihenfolge:

1. `not-found.tsx` selbst mit `'use client'` markieren und dort `next/dynamic(..., { ssr: false })`
   verwenden. Die Datei rendert ohnehin ausschliesslich eine Client-Komponente, es geht also kein
   serverseitig gerenderter Inhalt verloren.
2. `not-found.tsx` als Server Component belassen und eine schmale eigene `'use client'`-Datei
   dazwischenlegen, die den dynamischen Import kapselt.

Beide Wege erreichen das Ziel (eigener Chunk statt Teil des erfolgreichen oeffentlichen
Profilsegments). Welcher Weg gewaehlt wurde und warum, gehoert in die SUMMARY.

```tsx
export function OwnHiddenProfilePreview() {
  const pathname = usePathname()
  const { hasAccessToken, hasRefreshToken, isClientInitialized } = useAuthSession()
  ...
  const slug = getStoredSlug(pathname)
  const hasAuthSession = hasAccessToken || hasRefreshToken
  const { status, response } = useMemberViewer(slug, { enabled: isClientInitialized && hasAuthSession, retryKey })

  if (!isClientInitialized) return <LoadingProfile />
  if (!slug || !hasAuthSession) return <UnavailableProfile />
  if (status === 'loading') return <LoadingProfile />
  if (status === 'unavailable') return <UnavailableProfile />
  if (status === 'error') return (/* ErrorState + retry */)
  if (!response || !response.viewer.is_owner) return <UnavailableProfile />

  return <MemberProfileContent profile={response.data} storedSlug={slug} viewer={response.viewer} viewerResolved referenceNow={referenceNow} />
}
```
